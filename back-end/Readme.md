# Dental-Care

Trabalho referente disciplina de Laboratório de Programação e Desenvolvimento de Sistemas.

Este repositório foi criado para uma aplicação web full-stack envolvendo Java & Spring Boot para back-end, com JDK 21; HTML, CSS e JavaScript para o front-end com páginas estáticas.

### Atenção:
Recomendamos que para executar o projeto, possua todas as ferramentas e siga as instruções de execução.

#### Ferramentas 💻:

- IDE de sua preferência, mas, recomendamos o IntelliJ;
- Java instalado em sua máquina, preferencialmente com JDK21 ou JDK17;
- MySQL nativo;
