# Dental-Care
Trabalho para a disciplina de Programação e Desenvolvimento de Sistemas.
O projeto consiste no desenvolvimento de uma aplicação web para um sistema de gerenciamento de consultório odontológico.
A aplicação foi desenvolvida utilizando a linguagem Java com o kit de desenvolvimento JDK 21 na IDE IntelliJ IDEA, 
garantindo a padronização das ferramentas de compilação e refatoração do código-fonte.
Nesta etapa o foco foi no desenvolvimento do back-end do sistema.
Foram aplicados mecanismos de herança, abstração e polimorfismo, 
além da utilização da API de Coleções do Java para o gerenciamento dinâmico de dados em memória.
